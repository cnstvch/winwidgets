# WinWidgets

Лёгкий набор виджетов для Windows 10/11 в одном процессе: остров (медиа), часы, панель управления, док.
Без браузерного движка, ~30–50 МБ памяти, в простое почти 0% CPU.

## Как получить exe через GitHub

1. Создай репозиторий, залей содержимое этой папки (включая `.github/workflows/build.yml`).
2. Открой вкладку **Actions** → workflow **build** → дождись зелёной галочки (или нажми *Run workflow*).
3. Внизу страницы запуска, в **Artifacts**, скачай:
   - `WinWidgets-small` — ~2–5 МБ, нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0);
   - `WinWidgets-standalone` — ~60–80 МБ, работает без установки чего-либо.
4. Запусти `WinWidgets.exe`. Иконка появится в трее.

Если сборка упала — открой лог шага *Publish*, скопируй строки с `error CS...` и пришли мне.

## Что внутри

- **Челка** — единая чёрная форма сверху по центру, раскрывается пружиной; плеер с обложкой, прогрессом и кнопками.
- **Док** — светлое матовое стекло, увеличение иконок, подписи, точки у запущенных, корзина (как в macOS).
- **Панель управления** — раскладка как в macOS Control Center (светлая).
- **Часы** (цифровые, настраиваются), **аналоговые часы** и **календарь** — классические виджеты.

## Управление

| Что | Как |
|---|---|
| Панель управления | `Ctrl+Alt+C` или ЛКМ по иконке в трее |
| Настройки | двойной клик по цифровым часам / ПКМ → Настройки |
| Переместить часы и виджеты | перетащить мышью |
| Челка | наведи — развернётся плеер; на смену трека раскрывается сама |
| Док | наведи — иконки растут; ПКМ — закрепить/открепить |
| Выход, автозапуск | ПКМ по иконке в трее |

## Если что-то сломалось

- Лог ошибок: `%APPDATA%\WinWidgets\crash.log`.
- Если прошлый запуск упал на старте, при следующем конфиг сбросится сам (старый сохранится как `config.bad.json`).
- Ручной сброс: закрой программу и удали `%APPDATA%\WinWidgets\config.json`.

## Конфиг

`%APPDATA%\WinWidgets\config.json` применяется на лету. Через него: закреплённые приложения дока
(`Dock.Apps`, понимает `%APPDATA%` и т.п.), размер и увеличение иконок, скрытие панели задач Windows
(`Dock.HideWindowsTaskbar`), светлая/тёмная тема стекла (`Glass.Light`), размеры и позиции виджетов.

## Ограничения

- Яркость только на ноутбуках и встроенных экранах.
- Wi-Fi/Bluetooth через системные радио-API; Windows может спросить разрешение.
- Уведомления в челке не подключены — челка медиа-only.
- UWP-приложения (Калькулятор, Параметры) в доке не всегда видны как запущенные.
- Стекло — размытые обои + светлая подложка, а не живое размытие окон под панелью (зато почти бесплатно).
- Цифровые часы по умолчанию — обычное окно; `Clock.SendToBack: true` кладёт их под все окна (если пропадут — верни `false`).
