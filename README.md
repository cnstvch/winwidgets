# WinWidgets

Лёгкий набор виджетов для Windows 10/11 в одном процессе: остров (медиа), часы, панель управления, док.
Без браузерного движка, ~30–50 МБ памяти, в простое почти 0% CPU.

## Как получить exe через GitHub

1. Создай репозиторий, залей содержимое этой папки (включая `.github/workflows/build.yml`).
2. Открой вкладку **Actions** → workflow **build** → дождись зелёной галочки (или нажми *Run workflow*).
3. Внизу страницы запуска, в **Artifacts**, скачай:
   - `WinWidgets-small` — ~2–5 МБ, нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0);
   - `WinWidgets-standalone` — ~60–80 МБ, работает без установки чего-либо.
4. Запусти `WinWidgets.exe`. Иконка появится в трее.

Если сборка упала — открой лог шага *Publish*, скопируй строки с `error CS...` и пришли мне.

## Управление

| Что | Как |
|---|---|
| Панель управления | `Ctrl+Alt+C` или ЛКМ по иконке в трее |
| Настройки часов и стекла | двойной клик по часам / ПКМ по часам |
| Переместить часы | перетащить мышью |
| Остров | наведи — развернётся плеер; на смену трека раскрывается сам |
| Док | наведи — иконки увеличиваются; ПКМ — закрепить/открепить |
| Выход, автозапуск | ПКМ по иконке в трее |

## Конфиг

`%APPDATA%\WinWidgets\config.json` — применяется на лету при сохранении файла.
Через него настраиваются закреплённые приложения дока (`Dock.Apps`), размер и увеличение иконок,
скрытие панели задач Windows (`Dock.HideWindowsTaskbar`), параметры стекла (`Glass`), размеры острова.

## Ограничения

- Яркость работает на ноутбуках и встроенных экранах (внешние мониторы через WMI не управляются).
- Wi-Fi/Bluetooth переключаются через системные радио-API; на некоторых машинах Windows спросит разрешение.
- Уведомления в острове пока не подключены (читаются только через разрешение пользователя) — остров медиа-only.
- UWP-приложения (Калькулятор, Параметры) в доке показываются как запущенные не всегда: их окна принадлежат системному хосту.
- Часы по умолчанию — обычное окно без рамки. Хочешь, чтобы они лежали под всеми окнами — `Clock.SendToBack: true` в конфиге (если пропадут — верни `false`).
- «Стекло» — это размытые обои + блики + ободок, а не живое размытие содержимого окон под панелью.
  Зато почти не потребляет ресурсов. Если захочется настоящее Acrylic — добавим отдельным режимом.
